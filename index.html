📌 김비서의 추천 업무

작업을 등록하면 남은 양과 마감 정보를 기준으로 우선순위를 계산합니다. 실제 작업 시간이 쌓이면 김비서가 더 정확하게 판단할 수 있습니다.
작업을 진행한 뒤 각 작업의 현재 실적을 입력하고 「작업량 반영」을 누르면 잔여량·달성률·우선순위가 즉시 갱신됩니다.

➕ 오늘의 작업 추가

종료일을 비워두면 종료일 없이 반복됩니다.
ⓘ
오늘만 하는 작업은 오늘 마감 시간만 정하면 됩니다.
매일 또는 매주 목표 횟수를 선택할 수 있습니다. 주간 목표는 월요일부터 일요일까지 누적되며, 종료일은 선택사항입니다. 과거 기록과 통계는 보존됩니다.

📝 지난 작업 기록 추가

작업하느라 기록을 놓쳤다면 날짜를 선택해 나중에 실적을 입력할 수 있습니다. 이 기록은 오늘의 진행 상태를 바꾸지 않고 과거 기록과 통계에만 반영됩니다.
작업을 선택하면 목표와 단위가 표시됩니다.
